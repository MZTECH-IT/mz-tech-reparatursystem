Website-Integration: Terminbuchung & Reparaturanfrage

Fertiger HTML-Code zum Einfügen in Ihre bestehende Website (index.html), damit Besucher direkt online einen Termin vereinbaren oder eine Reparatur anfragen können — ohne Anruf, rund um die Uhr.

Inhalt

  1. Die zwei neuen Seiten (URLs)
  2. Buttons im Hero-Bereich einfügen (empfohlen)
  3. Button in der Navigation einfügen
  4. Buttons im Kontakt-Bereich einfügen
  5. Alternative: Schwebender Button (wie WhatsApp-Button)
  6. Wichtige Hinweise

1 Die zwei neuen Seiten

Ihr Reparatursystem stellt zwei öffentliche Formulare bereit, auf die Sie von Ihrer Website aus verlinken:

Terminbuchung — Kunde wählt Datum & Uhrzeit direkt online:

https://mztech-it.de/repair_neu/public/termin.php

Reparaturanfrage — Kunde beschreibt sein Problem, MZ Tech meldet sich zurück:

https://mztech-it.de/repair_neu/public/anfrage.php
Hinweis zum Pfad: Falls Sie das Reparatursystem später in einen anderen Ordner oder auf eine Subdomain verschieben (z. B. https://buchung.mztech-it.de/), müssen Sie in allen unten stehenden Code-Blöcken nur die URL in den href="…"-Attributen entsprechend anpassen — sonst ändert sich nichts.

2 Buttons im Hero-Bereich einfügen (empfohlen)

Öffnen Sie index.html Ihrer Website und suchen Sie nach class="hero-btns" (im Bereich <section id="hero">). Ersetzen Sie den bestehenden Block durch diesen: 

<div class="hero-btns">
  <a href="https://mztech-it.de/repair_neu/public/termin.php" class="btn-primary">📅 Termin vereinbaren</a>
  <a href="https://mztech-it.de/repair_neu/public/anfrage.php" class="btn-outline">🔧 Reparatur anfragen</a>
  <a href="https://mztech-it.de/repair_neu/public/portal.php" class="btn-outline">👤 Kundenportal</a>
  <a href="https://mztech-it.de/repair_neu/public/portal_business.php" class="btn-outline">🏢 Firmenkundenportal</a>
  <a href="https://mztech-it.de/repair_neu/public/portal_business.php?view=tickets" class="btn-outline">🎫 Ticket erstellen</a>
  <a href="#leistungen" class="btn-outline">Leistungen ansehen</a>
</div>

Vorschau, wie das im Browser aussieht:

📅 Termin vereinbaren 🔧 Reparatur anfragen

3 Button in der Navigation einfügen

Suchen Sie in index.html nach <ul class="nav-links" id="nav-links"> und ersetzen Sie den bisherigen Kontakt-Menüpunkt durch diese zwei Einträge (oder fügen Sie sie zusätzlich ein): 

<li><a href="https://mztech-it.de/repair_neu/public/termin.php">Termin vereinbaren</a></li>
<li><a href="https://mztech-it.de/repair_neu/public/anfrage.php" class="nav-cta">Reparatur anfragen</a></li>
<li><a href="https://mztech-it.de/repair_neu/public/portal.php">Kundenportal</a></li>
<li><a href="https://mztech-it.de/repair_neu/public/portal_business.php">Firmenkundenportal</a></li>
Tipp: Die Klasse nav-cta ist bereits in Ihrem style.css definiert (farblich hervorgehoben) — Sie müssen nichts an der CSS-Datei ändern.

4 Buttons im Kontakt-Bereich einfügen

Im Abschnitt <section id="kontakt"> steht aktuell nur ein Kontaktformular. Fügen Sie direkt darüber (z. B. nach <p class="section-sub">…</p>) diesen Block mit zwei großen Aktions-Karten ein: 

<div style="display:flex;gap:16px;flex-wrap:wrap;margin:24px 0 32px;">
  <a href="https://mztech-it.de/repair_neu/public/termin.php"
     style="flex:1;min-width:260px;background:#fff;border:2px solid #0057B8;border-radius:12px;
            padding:24px;text-decoration:none;color:#1a1f2b;display:block;">
    <div style="font-size:1.8rem;margin-bottom:8px;">📅</div>
    <strong style="font-size:1.1rem;color:#0057B8;">Termin online vereinbaren</strong>
    <p style="margin:8px 0 0;color:#6B7280;font-size:.9rem;">Wählen Sie direkt einen freien
       Termin aus unserem Kalender — ganz ohne Anruf.</p>
  </a>
  <a href="https://mztech-it.de/repair_neu/public/anfrage.php"
     style="flex:1;min-width:260px;background:#0057B8;border-radius:12px;padding:24px;
            text-decoration:none;color:#fff;display:block;">
    <div style="font-size:1.8rem;margin-bottom:8px;">🔧</div>
    <strong style="font-size:1.1rem;">Reparatur unverbindlich anfragen</strong>
    <p style="margin:8px 0 0;color:#dbe8ff;font-size:.9rem;">Beschreiben Sie kurz das Problem —
       wir melden uns mit einem Vorschlag zurück.</p>
  </a>
</div>

5 Alternative: Schwebender Button (wie der WhatsApp-Button)

Ihre Website hat bereits einen schwebenden WhatsApp-Button unten rechts. Sie können nach dem gleichen Muster einen zweiten schwebenden Button für die Terminbuchung ergänzen. Fügen Sie diesen Code kurz vor </body> ein (am besten direkt neben dem bestehenden WhatsApp-Button-Code): 

<a href="https://mztech-it.de/repair_neu/public/termin.php"
   style="position:fixed;bottom:96px;right:24px;background:#0057B8;color:#fff;
          width:56px;height:56px;border-radius:50%;display:flex;align-items:center;
          justify-content:center;font-size:1.5rem;text-decoration:none;
          box-shadow:0 4px 14px rgba(0,0,0,.25);z-index:999;"
   title="Termin vereinbaren">📅</a>
Empfehlung: Nutzen Sie entweder die Hero-Buttons (Schritt 2) oder den schwebenden Button — beides gleichzeitig kann auf kleinen Bildschirmen unübersichtlich wirken.

6 Wichtige Hinweise

  • Die verlinkten Seiten öffnen sich innerhalb derselben Website (kein neues Fenster) — Besucher bleiben im gewohnten Look, da beide Formulare farblich an Ihre Website (Blau #0057B8) angepasst sind.
  • Beide Formulare funktionieren ohne Login und ohne zusätzliche Kosten.
  • Neue Terminanfragen erscheinen automatisch unter „Terminanfragen“, neue Reparaturanfragen unter „Online-Anfragen“ in Ihrem Admin-Bereich (https://mztech-it.de/repair_neu/public/), inklusive automatischer Bestätigungs-E-Mail an den Kunden.
  • Sie können die Online-Terminbuchung und die Online-Reparaturanfrage jederzeit einzeln in den Einstellungen Ihres Admin-Bereichs deaktivieren, falls Sie z. B. zeitweise überlastet sind — die Buttons auf der Website bleiben dann sichtbar, zeigen dem Kunden aber automatisch einen Hinweis, dass die Online-Annahme aktuell pausiert ist.
  • Es ist keine Änderung an der PHP-Datei contact.php Ihrer bestehenden Website nötig — die neuen Formulare laufen komplett unabhängig im Reparatursystem.
